## PHASE 1 — Embedded Knowledge

### 1A: Products and Modules

Rapid e-Suite implements Oracle NetSuite ERP. The Flat-RapidHeading BRD covers these modules:

**Core Setup**
- **Subsidiary Structure**: Multi-entity hierarchy; parent-child subsidiaries per legal entity; NetSuite OneWorld required for multi-subsidiary.
- **Location**: Physical and virtual locations linked to subsidiaries; inventory and non-inventory location types.
- **Department**: Cross-subsidiary departments; auto-filter on transactions by subsidiary association.
- **Class**: Additional reporting dimension (Line of Business); appears on all transactions as a classification field.
- **Discipline**: Custom segment for client-specific segmentation (e.g. project type, division).
- **Dashboard and Reminders**: Role-based dashboard configuration; published by Administrator; includes KPIs, reminders, and saved searches.
- **Role and Permissions**: 50+ standard NetSuite roles; custom roles configurable from standard; role matrix provided by client. Administrator has full access.

**Masters**
- **Customer Master**: Company/individual customer records; multi-currency; Projects/Non-Projects categorisation; field-detail table has 76 standard + custom fields.
- **Vendor Master**: Supplier records; multi-currency; Procurement and Finance role access; field-detail table has 50 fields.
- **Employee Master**: Employee records for expense reporting, project assignment; 41 standard fields.

**Design to Build (Inventory)**
- **Item Master**: Inventory, Non-Inventory, Service item types; Lot Numbered; Item Group sub-types; 42 fields.
- **Transfer Order / Inventory Transfer**: Multi-Location Inventory; stock movement between sites/warehouses; standard transfer order module.
- **Inventory Adjustment**: Inventory Worksheet or Inventory Adjustment forms; adjusts on-hand quantities.

**Project Management**: Project records linked to customers and subsidiaries; time tracking; project billing.

**CRM**
- **Lead**: Potential customers; standard NS lead record.
- **Prospect**: Converting leads to prospects; opportunity tracking.
- **Contact**: Contact records linked to customers/vendors.
- **Opportunity**: Pipeline tracking; won/lost stages.
- **Estimate (RFQ)**: Request for Quote; converts to Sales Order.

**Order to Cash**
- **Sales Order**: Commitment to sell; fulfillment workflow; status tracking.
- **Revenue Recognition**: Deferred revenue accounts; recognition templates; schedule-based JE generation.
- **Customer Invoice**: Invoice from SO or standalone; AR management.
- **Customer Payment**: Payment application against open invoices.

**Return to Credit**
- **Return Authorization (RA)**: Records return commitment; links to original SO.
- **Customer Credit Memo**: Credit issued against RA or standalone.
- **Customer Refund**: Cash refund to customer.

**Procure to Pay**
- **Purchase Requisition**: Internal request initiating PO workflow.
- **Purchase Contract**: Contracted pricing/terms for repeat purchases.
- **Blanket Purchase Order**: Fixed-price preset quantity PO for a time period.
- **Purchase Order**: Commitment to buy; GRN/item receipt workflow.
- **Item Receipt (GRN)**: Records receipt against PO; triggers vendor bill creation.
- **Vendor Bill**: Supplier invoice; AP management.
- **Vendor Bill Payment**: Payment against open vendor bills.
- **Vendor Pre-Payment**: Advance payment to vendor; applied to future bills.

**Return to Debit**
- **Vendor Return Authorization**: Non-posting transaction recording return to vendor.
- **Vendor Credit**: Credit from vendor applied against AP.

**Other**
- **SAML Single Sign-On**: SSO integration using SAML 2.0.
- **Fixed Asset Management (FAM)**: Automated acquisition, depreciation, revaluation, retirement.

**Record to Report**
- **COA**: Chart of Account; subsidiary-restricted or shared; account types (Bank, AR, OCA, Fixed Asset, Other Asset, AP, OCL, LTL, Equity, Income, COGS, Expense, Other Income, Other Expense).
- **Currency and Exchange Rate**: Multi-currency; exchange rate schedules.
- **Payment Terms**: Vendor and customer payment terms; due date auto-calculation.
- **Tax Codes and Rates**: GST/VAT configuration; tax code on transactions.
- **Journal Entries**: Manual GL entries; intercompany JEs.
- **Transfer Funds**: Bank-to-bank transfers within NetSuite.
- **Write Check**: Non-PO expense payments and non-check transactions.
- **Bank Reconciliation**: Matching NS transactions to bank statements.
- **Amortization**: Deferred purchase expense amortization schedules.
- **Expense Allocation**: Fixed-expense allocation across dimensions without direct transaction entry.
- **Expense Reporting**: Employee expense reports; approval workflow; conversion to vendor bills.
- **Budgets**: Financial planning budgets by GL account and period.
- **Period Close**: Accounting period lock; status changes Open → Locked → Closed.
- **Foreign Currency Revaluation**: Revaluing foreign-currency balances at current exchange rates; generates JEs.
- **Reports**: Standard NS reports (P&L, Balance Sheet, AR Aging, AP Aging, etc.); Rapid customises additional reports per client request.

**Data Migration**: Rapid migrates master data (Customer, Vendor, Item, Employee, COA, Subsidiaries) and open transactions (AR, AP, opening balances) as of cut-off date using client-supplied templates.

```python
#!/usr/bin/env python3
"""
Rapid e-Suite NetSuite BRD Generator — Flat-RapidHeading Variant
Usage: python3 generate_brd.py --mom <mom_path> --output <output_path>
"""

import os
import sys
import json
import argparse
from pathlib import Path
from docx import Document
from docx.shared import Pt, Inches, RGBColor, Cm, Emu
from docx.enum.text import WD_ALIGN_PARAGRAPH
from docx.oxml.ns import qn
from docx.oxml import OxmlElement
import copy

# ─── CONFIGURATION ───────────────────────────────────────────────
SAMPLE_PATH = "/Users/likeminds/agentic-workflow-backend/inputs/sample_artifacts/rapid_suite/FRP - BRD Version 1.0.docx"
ASSETS_DIR  = "/Users/likeminds/agentic-workflow-backend/assets/frp"

# Section images (REUSABLE_STANDARD) — relative to ASSETS_DIR
SECTION_IMAGES = {
    "Design to Build":           "image2.png",
    "Order to Cash":             "image3.png",
    "Return to Credit":          "image4.png",
    "Return to Debit":           "image6.png",
    "Record to Report":          "image7.png",
    "Expense Allocation":        "image8.png",
    "Period Close":              "image9.png",
    "Foreign Currency Revaluation": "image10.png",
}

# ─── STYLE NAMES (from sample DOCX) ──────────────────────────────
S_RAPID_HDG    = "Rapid Heading"      # top-level: Project Details, Doc Revision, Abbrev.
S_RAPID_H1     = "Rapid Heading 1"    # section H1: Introduction, Customer Master, etc.
S_RAPID_H1_1   = "Rapid Heading 1.1." # sub-section H2: As-Is Scenario, sub-processes
S_NO_SPACING   = "NoSpacing"          # body paragraphs (justified, no spacing)
S_NORMAL1      = "Normal1"            # body alternative with 80/80 spacing
S_LIST_PARA    = "List Paragraph"     # Verdana 10pt indented list
S_BRD_BULLET   = "BRD-Bullet List"    # Calibri 10pt bullet list
S_BRD_TABLE    = "BRD Table Text"     # Calibri 10pt table body text
S_TABLE_HDR    = "Table Header"       # Arial bold white — table header cells
S_BODY_TEXT    = "Body Text"          # Arial 14pt bold right-align — cover logo area

# ─── TABLE COLUMN WIDTHS (in dxa) ────────────────────────────────
COL_WIDTHS_FIELD_DETAIL = [704, 1843, 1701, 1843, 1559, 1701]
COL_WIDTHS_PROJECT      = [2405, 284, 6661]
COL_WIDTHS_REVISION     = [1271, 1559, 2694, 1275, 1276, 1276]

# ─── EMBEDDED FIELD TABLES (Phase 1C) ────────────────────────────
# [PASTE FIELD_TABLES dict here from 1C catalog — see Phase 1C above]
FIELD_TABLES = {}  # populated by the generator — see 1C catalog

# ─── HELPERS ─────────────────────────────────────────────────────

def asset(filename):
    return str(Path(ASSETS_DIR) / filename)

def add_paragraph(doc, text, style=S_NO_SPACING):
    """Add a paragraph with the given style."""
    p = doc.add_paragraph(text, style=style)
    return p

def add_heading(doc, text, style):
    """Add a heading paragraph with exact style name."""
    p = doc.add_paragraph(style=style)
    p.add_run(text)
    return p

def add_table_with_header(doc, headers, rows, col_widths=None, style="TableGridLight"):
    """Add a table with grey header row (#D9D9D9 shading)."""
    table = doc.add_table(rows=1, cols=len(headers))
    table.style = style

    # Header row
    hdr_row = table.rows[0]
    for i, hdr in enumerate(headers):
        cell = hdr_row.cells[i]
        cell.text = hdr
        # Apply #D9D9D9 shading
        tc = cell._tc
        tcPr = tc.get_or_add_tcPr()
        shd = OxmlElement('w:shd')
        shd.set(qn('w:val'), 'clear')
        shd.set(qn('w:color'), 'auto')
        shd.set(qn('w:fill'), 'D9D9D9')
        tcPr.append(shd)
        # Bold text in header
        for para in cell.paragraphs:
            for run in para.runs:
                run.bold = True

    # Data rows
    for row_data in rows:
        row = table.add_row()
        for i, cell_text in enumerate(row_data):
            if i < len(row.cells):
                row.cells[i].text = cell_text

    # Set column widths
    if col_widths:
        for i, width in enumerate(col_widths):
            for row in table.rows:
                row.cells[i].width = Emu(width * 914)  # dxa to EMU (1 dxa = 914.4 EMU)

    return table

def add_field_detail_table(doc, section_name):
    """Insert field-detail table for a section from the 1C catalog."""
    if section_name not in FIELD_TABLES:
        return
    info = FIELD_TABLES[section_name]
    add_table_with_header(doc, info["headers"], info["rows"], COL_WIDTHS_FIELD_DETAIL)
    doc.add_paragraph()  # spacing after table

def add_section_image(doc, section_name):
    """Insert process-flow image for section if available."""
    if section_name not in SECTION_IMAGES:
        return
    img_path = asset(SECTION_IMAGES[section_name])
    if os.path.exists(img_path):
        p = doc.add_paragraph()
        run = p.add_run()
        run.add_picture(img_path, width=Inches(6.0))
        p.alignment = WD_ALIGN_PARAGRAPH.CENTER
    else:
        add_paragraph(doc, f"[PROCESS FLOW DIAGRAM — {section_name} — insert image here]")

def add_role_report_dm(doc, role=None, report=None, dm=None):
    """Add Role/Report/Data Migration closing lines."""
    if role:
        add_paragraph(doc, role)
    if report:

                if 'FRP Products Co., Pte Ltd' in run.text:
                    run.text = run.text.replace('FRP Products Co., Pte Ltd', client_legal_name)
                # Also handle any other prior client name patterns

def load_mom(mom_path):
    """Load MOM data from JSON or parse from text file."""
    path = Path(mom_path)
    if path.suffix == '.json':
        with open(path) as f:
            return json.load(f)
    else:
        # If MOM is a plain text transcript, parse key fields manually
        # and return a dict with the fields extracted
        text = path.read_text()
        mom = {}
        # Basic extraction patterns
        import re
        patterns = {
            'client_legal_name': r'(?:Client(?:\s+(?:is|name|legal name))?|Customer Name)\s*:?\s*([A-Z][^,\n]{5,60}(?:Pte\.?\s*Ltd\.?|Inc\.?|LLC|Corp\.?|Ltd\.?))',
            'ns_version':        r'(?:NS|NetSuite)\s+version\s*:?\s*([\d.]+)',
            'ns_account_number': r'(?:Account\s+(?:Number|No\.?)|NS\s+Account)\s*:?\s*(\d{5,10})',
        }
        for key, pat in patterns.items():
            m = re.search(pat, text, re.IGNORECASE)
            if m:
                mom[key] = m.group(1).strip()
        return mom
```
